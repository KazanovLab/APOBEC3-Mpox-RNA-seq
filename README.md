# APOBEC3-Mpox-RNA-seq

This repository contains all scripts and data developed during the study “Analysis of MPXV RNA-seq Data Reveals Lack of Evidence of APOBEC3-mediated RNA Editing.”

The directory `cppsrc` includes source code for two C++ programs used to generate mismatch positions from VCF files (the commands used to generate VCF files are provided in Table S2 of the manuscript). The first program, `mpoxvcf`, selects mismatch positions for all three read-mapping approaches described in the Methods: (1) mapping only to the viral genome, (2) mapping to the combined human+MPXV genome, and (3) mapping first to the human genome and then remapping unmapped reads to the MPXV genome. The resulting files are stored in the `data` directory in the format `<sample_ID>_<mapping type>_bcftools.txt`, where the mapping types (`mpox`, `hybrid`, and `host`) correspond to the three mapping approaches. The second program, `mpoxconsensus`, generates consensus positions and writes the output files to the `data` directory in the format `<sample_ID>_bcftools.txt`.

The directory `R_python` contains all scripts required to generate all figures using the selected mismatch positions stored in the 'data' directory. Additional directories include: `coverage`, containing genome coverage data used in Figure 3 and produced by a dedicated script; `IR`, containing summarized data on inverted repeats generated by Palindrom Analyzer; `NCBIgenome`, containing the reference MPXV genome; `positions`, which holds a non-redundant list of substitution positions filtered by substitution frequency (SF > 0.5); `SecondaryStructure`, containing predicted secondary structure information produced using the RNAsselem package; and `Specificity`, which contains models of DNA-binding specificity for APOBEC family members.
